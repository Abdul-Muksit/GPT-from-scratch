# GPT from scratch

A character-level, decoder-only GPT language model implemented from scratch in PyTorch and trained on the
Tiny Shakespeare dataset. This is a learning project: the goal is to understand every component
(causal self-attention, residual blocks, LayerNorm, training loop, sampling) by writing it by hand.

## Acknowledgements

The architecture and training setup follow Andrej Karpathy's
["Let's build GPT: from scratch, in code, spelled out"](https://www.youtube.com/watch?v=kCc8FmEb1nY) lecture
(and his `ng-video-lecture` / `nanoGPT` repositories). This repository is my own re-implementation with the
changes listed below; it is not an original architecture.

Changes relative to the lecture code:

- All attention heads run in one batched `F.scaled_dot_product_attention(..., is_causal=True)` call instead of a Python loop over `Head` modules.
- GELU activation and GPT-2 style weight initialisation (`N(0, 0.02)`, residual output projections scaled by `1/sqrt(2 * n_layer)`).
- Model hyperparameters live in a `GPTConfig` dataclass; the device is read from the input tensor rather than stored in the model.
- `forward()` always returns logits of shape `(B, T, vocab_size)`.
- `generate()` runs under `torch.no_grad()`, samples with dropout disabled, restores the previous train/eval mode, and supports temperature and top-k.
- Linear warmup + cosine learning-rate decay, gradient-norm clipping, command-line arguments.
- Checkpoints contain the weights, the model config and the character vocabulary, so `sample.py` needs no dataset.
- Unit tests (causality, shapes, initial loss, single-batch overfitting, generation, checkpoint round trip).

## Setup

```bash
pip install -r requirements.txt   # requires torch >= 2.0
```

## Train

```bash
python train.py                                   # defaults below
python train.py --max_iters 5000 --batch_size 32  # override any option; see: python train.py --help
```

The Tiny Shakespeare dataset is downloaded to `input.txt` on first run. A checkpoint is saved to
`checkpoints/gpt_model.pt`.

Default configuration: `n_embd=384`, `n_head=6`, `n_layer=6`, `block_size=256`, `dropout=0.2`,
`batch_size=64`, `learning_rate=3e-4` (cosine decay to `3e-5`, 100 warmup steps), `max_iters=2000`.
A GPU is strongly recommended; on CPU this configuration is very slow.

## Generate text

```bash
python sample.py
python sample.py --prompt "ROMEO:" --max_new_tokens 300 --temperature 0.8 --top_k 40
```

## Project layout

```
model.py            GPTConfig, attention, blocks, GPTLanguageModel (+ generate)
train.py            data loading, training loop, checkpoint saving
sample.py           load a checkpoint and generate text
tests/test_model.py unit tests
conftest.py         empty; makes pytest add the repo root to sys.path
```

## Limitations

- Character-level tokenizer, so the vocabulary is only ~65 symbols and sequences are long.
- Small dataset (about 1 MB); the model overfits easily.
- No KV-cache, so generation is slow for long outputs.
- No mixed precision or multi-GPU training.
- Generated text is Shakespeare-like in form, not in meaning.
